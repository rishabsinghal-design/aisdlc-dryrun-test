# aisdlc-dryrun-test

A simple **React Hello World** application.

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) v16 or higher
- npm (comes with Node.js)

### Install dependencies
```bash
npm install
```

### Run the development server
```bash
npm start
```
Opens [http://localhost:3000](http://localhost:3000) in your browser.

### Run tests
```bash
npm test
```

### Build for production
```bash
npm run build
```
Outputs optimised static files to the `build/` directory.
